# Student Management System

A simple Student Management System developed in C to manage student records.

## Features

- Add Student
- Display Students
- Search Student
- Update Student
- Delete Student
- Exit the program

## Technologies Used

- C Programming
- Structures
- Arrays
- Functions
- Loops
- Conditional Statements

## How to Run

1. Download or clone this repository.
2. Compile the program using a C compiler.
3. Run the executable file.
4. Select an option from the menu.

## Sample Menu

===== STUDENT MANAGEMENT SYSTEM =====

1. Add Student
2. Display Students
3. Search Student
4. Update Student
5. Delete Student
6. Exit

## Project Purpose

This project is developed to practice C programming concepts
and understand how student records can be managed using a
menu-driven application.
